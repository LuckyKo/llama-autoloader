API Reference 
LM Studio-compatible:
  GET  /v1/models                              list models (loaded + unloaded)
  GET  /v1/models/{id}                         model info + config
  POST /v1/chat/completions                    { "model": "...", ... }  (auto-loads if needed)
  POST /v1/completions                         OpenAI-style
  POST /v1/embeddings                          OpenAI-style

Extensions:
  GET  /health                                 autoloader health check
  GET  /v1/status                              launcher + GPU + RAM + per-model usage
  PUT  /v1/models/{id}/config                  update sidecar config JSON
  POST /v1/models/{id}/load                    JIT-load a model
  POST /v1/models/{id}/interrupt              cancel in-flight generation (soft; ?hard=true to kill+unload)
  POST /v1/models/{id}/unload                  unload
  POST /v1/models/{id}/state/save              {"label":"default"} save slot 0
  POST /v1/models/{id}/state/load              {"label":"default"} restore slot 0
  GET  /v1/models/{id}/state                   list saved labels
  DELETE /v1/models/{id}                      delete an engine bridge card
DELETE /v1/models/{id}/state/{label}         delete saved label
  POST /v1/scan                                rescan root dir for *.gguf + engine bridge cards
  GET  /v1/engines                             configured engines + why one is unusable
  POST /v1/models/engine                       add a bridge card {"engine": "strata", "engine_config": "path.json"}
  POST /v1/models/strata                       DEPRECATED alias of the above (engine "strata" only)
  POST /v1/unload_all                          unload everything
  POST /v1/raw/{id}/{path}                     raw pass-through to llama-server
  GET  /v1/mmproj                             vision projectors + which model owns each
  WS   /ws                                     live status stream (1 Hz)

Example cURL:
  curl http://localhost:9123/v1/chat/completions \
       -H 'Content-Type: application/json' \
       -d '{"model":"Qwen2.5-7B-Instruct.Q4_K_M.gguf",
            "messages":[{"role":"user","content":"Hello!"}],
            "stream":true}'

Global Settings

Extra flags for all llama-server instances. Default includes --cache-ram 16384 --kv-unified (16 GiB prompt cache). Requires 32+ GB RAM for safe operation.
Host / Port require a restart to take effect.
